# Artbrush Sticker

Implemented from the supplied static screenshot and user-requested two-word entrance, using the supplied ArtBrush Medium font. Editable caption text feeds the shared renderer for both editors, style cards and export.

The AEP header and SHA-256 are recorded under work/aep/aeArtbrushSticker. After Effects is not installed at the inspected Adobe location. No AE composition, expressions or animation tracks were extracted. Exact adaptation needs an AE-generated property export and animation preview. Colour, stroke widths, halo and 140 ms fade are approximations/design choices, not measured AE properties. The source AEP remains unchanged and is not published.

Advanced word reveal supports batches of 1–6 words. A pair uses the first word speech timestamp; without word timing it uses uniform spacing. Font, face colour, outline colours and inner width remain editable. Source frame rate, dimensions, duration, plugins and 3D remain unknown. No claim of visual equivalence.

Status: implemented; validation: not-run. Tests, browser comparison, diacritics and MP4 verification deferred under the user agreement.
